# Mirak Odoo Modules — Free Editions

Public repository of the free Mirak Odoo editions. These modules are free of charge.

| Module | Purpose | Free |
|---|---|---|
| `mirak_shopify_connector_trial` | Shopify two-way sync — free trial | ✅ |
| `mirak_shopify_connector_trial` | Shopify two-way sync — free trial | ✅ |
| `mirak_snoonu_connector_trial` | Snoonu prices, stock and visibility — 30-day trial | ✅ |
| `mirak_uae_einvoice` | UAE PINT-AE e-invoicing — 15-document trial | ✅ |

Each Odoo series has its own branch, with the free modules at the repository root:

| `18.0` | `mirak_shopify_connector_trial`, `mirak_snoonu_connector_trial`, `mirak_uae_einvoice` |
